# Виселица

Консольная игра в угадывание слов, написанная на Go в процедурном стиле. Игрок угадывает слово по буквам, пока не потратит все попытки — с каждой ошибкой на экране «дорисовывается» виселица.

---

## Структура проекта

Весь код находится в одном пакете `main`. Для удобства чтения он разделён по файлам:

| Файл | Назначение |
|---|---|
| `main.go` | Главный цикл: отображение меню, запуск новых раундов, ведение игрового состояния |
| `dictionary.go` | Инициализация словаря и выбор случайного слова |
| `game_loop.go` | Определение того, завершён ли игровой раунд (победа или проигрыш) |
| `input.go` | Работа с пользовательским вводом и его валидация |
| `mask.go` | Создание, сравнение и отрисовка маски слова |
| `pictures.go` | Срез с картинками виселицы и функция отрисовки стадии в зависимости от количества ошибок |

---

## Правила игры

1. Программа загадывает случайное слово из словаря и показывает его маску — вместо каждой буквы стоит `_`.
2. Игрок вводит по одной букве за ход. Повторные буквы не считаются ошибкой, но и результата не дают.
3. Если буква есть в слове — она открывается во всех позициях.
4. Если буквы нет — засчитывается ошибка, и на экране появляется следующая стадия виселицы.
5. Игра заканчивается:
   -  **победой**, если слово угадано полностью;
   -  **проигрышем**, если попытки закончились раньше.

Количество попыток ограничено количеством стадий виселицы (обычно 6–7).

## Запуск

```bash
# собрать и запустить
go run .

# или собрать бинарник
go build -o hangman
./hangman
```

> 💡 `go run .` запускает все файлы пакета `main` в текущей директории, поэтому отдельные шаги сборки не нужны.
